# Tri-Cass Kodi add-on (HAP-61)

Thin **Chat + Knowledge Vault** plugin for Kodi (Pi / TV boxes already on Kodi).

## Install

1. Zip `plugin.program.tricass/` (the folder must be the zip root name
   `plugin.program.tricass`).
2. Kodi → Add-ons → Install from zip file.
3. Settings: Ollama URL (optional) + Vault folder (USB `Knowledge/` tree).

## Scope

- Remote-friendly list + keyboard prompts
- Chat via local Ollama, TinyChat phrases if Ollama is down
- Vault: walk `.md`/`.txt` and show simple substring hits

Not a full Tri-Cass Companion (no agent file tools / packs marketplace).

Icon: drop a 256×256 PNG at `plugin.program.tricass/resources/icon.png` before
shipping a release zip (placeholder optional).
