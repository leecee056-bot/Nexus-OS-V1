# NEXUS Companion — agent notes

- This folder is the **Windows + iOS + Android companion app** (Expo). Secondary to USB/Pi images and Cardputer/Pocket firmware.
- Chat is a phrase stub in `src/chat/tinychat.ts`, not a neural model.
- Vault/Files/Packs use AsyncStorage (+ document picker / file read) on-device.
- BootSplash + MatrixRain are intentional UI showpieces; keep the rabbit logo present.
- Android APK: `eas.json` preview profile → GitHub Releases (not Play Store yet).
- Do not claim Network chat is live. Keep offline-first wording.
- Site pointers: `/download#companion`, `public/guides/companion-app.md`, `public/guides/android-apk.md`.
