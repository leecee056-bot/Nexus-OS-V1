# NEXUS Companion (Windows + iOS)

Canonical instructions: [`../nexus-app/README.md`](../nexus-app/README.md)  
Short site guide: [`../public/guides/companion-app.md`](../public/guides/companion-app.md)

## Intent

Give people an installable Windows / iPhone / iPad app that mirrors the
offline-first core (Chat, Vault, Files) without flashing USB/Pi media or using
ESP32 hardware. Remains a **secondary** target next to the bootable OS and
Cardputer firmware. Network community features can hook in later.
