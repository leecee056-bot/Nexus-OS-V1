# Knowledge Vault starter pack

These short notes ship with NEXUS OS so Chat and the Vault have useful offline context on first boot.

They are **not** a full encyclopedia. Add your own `.txt` / `.md` files under `AI_DATA/knowledge/raw`, then rebuild the Vault index from the menu (Knowledge Vault → rebuild).

Included:

- `nexus-guide.md` — what NEXUS OS is
- `glossary.md` — plain-English terms
- `howto-flash-boot.md` — flash and boot checklist
- `howto-chat-vault.md` — Chat + Vault tips
- `howto-add-models.md` — adding larger GGUF models
- `howto-cyberdeck-pi.md` — Pi / cyberdeck notes
