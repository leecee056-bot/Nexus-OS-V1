# How to: Chat and Knowledge Vault

## Chat

1. From the hub, open **AI Chat**.
2. Type a question and press Enter. Replies come from the local model (bundled SmolLM2 unless you switched models).
3. Esc returns to the hub. No cloud account is required.

## Knowledge Vault

1. Open **Knowledge Vault** from the hub (or Agents → vault tools).
2. Starter notes already live under `AI_DATA/knowledge/raw`.
3. Copy your own `.txt` / `.md` files into that folder (File Manager helps).
4. Press **b** (rebuild) so the search index updates.
5. Search from the Vault UI. In Settings, you can enable vault RAG so Chat cites matching notes.

## Tips

- Short, clear note files work better than huge dumps.
- Rebuild after adding or editing files.
- Vault data stays on the stick/card — it does not upload to the website.
