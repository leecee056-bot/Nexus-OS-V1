# Tri-Cass OS Guide

Tri-Cass OS is a portable offline AI system. You write a disk image to a USB stick (PC) or microSD card (Raspberry Pi), boot from that media, and land on a keyboard-friendly hub with the rabbit wizard branding.

## What you get

- Local chat with a small GGUF model (no cloud, no account)
- Knowledge Vault for notes and how-tos on the stick
- Agents & Tools that can scaffold simple apps under `/data/projects/`
- File Manager scoped to `AI_DATA` (`/data`)

## First boot

1. You should see **Tri-Cass OS** and the rabbit mark.
2. Pick a theme and an available model.
3. Finish → main menu → AI Chat.

Companion apps on Windows / Mac / Android share the same brand and can build local project files the same way.
