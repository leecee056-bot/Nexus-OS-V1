# Project templates (Pocket Agent)

Used by `scaffold <template> <name>` on Tri-Cass OS images and mirrored into
Companion Agent plans.

| Id | Purpose |
|----|---------|
| `html-app` | Static HTML/CSS/JS panel app |
| `timer-app` | Ready countdown timer (HTML) |
| `python-cli` | Stdlib CLI script |
| `flask-app` | Tiny local HTTP app (stdlib; Flask optional later) |

Copies land in `/data/projects/<name>/` (images) or Companion Files workspace.
