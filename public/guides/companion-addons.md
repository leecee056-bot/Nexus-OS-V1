# Companion Add-ons marketplace

One-tap downloads for ready-made mini apps and a few official tool pages —
without building each tool from scratch.

## Where

Companion → **Add-ons** (Plugins). Tabs:

| Tab | What you get |
|-----|----------------|
| **Agent tools** | Toggle Vault / Files tools for Chat Agent |
| **Everyday** | Clock, calculator, timer, tip calc, … (~12) |
| **Coding** | JSON, regex, Base64, UUID, HTML sandbox, … |
| **Media & fun** | Drawing pad, dice, typing test, plus VS Code / Godot links |
| **Study & office** | Kanban, CSV viewer, notes templates, LibreOffice / Obsidian links |

## How Download works

- **Mini apps** — a complete HTML page is written into **Files / apps/…**. Open
  it from Files to use it offline (live preview on desktop/web).
- **Link items** — opens the vendor’s download page in Tri-Cass Browse (desktop)
  or your system browser.

Thumbnails, names, and short descriptions show on each card so you can pick
quickly. Tap **Download** once — done.

## Notes

Marketplace pages ship with Companion; they do not require a Tri-Cass cloud
account. Link downloads still need the network for the vendor site.
