# Companion “Check for updates”

Lightweight, optional way to see if something newer exists — without NEXUS
hosting the large files.

## What it does

Each curated item (chat model, image model, add-on / plugin, knowledge pack)
can show **Check for updates**. Tapping it opens the official page for that
item (Ollama library, guide, public archive, etc.).

**Check for OS updates** points at the project Download page and GitHub
releases so you can see newer USB / Pi images, Companion builds, and related
artifacts.

Nothing is scanned in the background in this version. A manual tap is enough.

## Where to find it

| Place | What opens |
|-------|------------|
| Chat → model cards / strip | Ollama library for that model; Agent guide; OS download |
| Image Lab → model cards | Ollama library / image guide / ComfyUI |
| Add-ons | Per-plugin guide link + Agent + OS |
| Knowledge Packs | Source archive URL + OS |
| About / Terminal Welcome | OS download, releases, Companion releases |

## Later

The same link pattern can attach to bootable OS image cards and Cardputer
firmware entries on the site and in future companion shells — still curated
links, still optional.
