# UI kit — free assets for local apps

These files ship on Tri-Cass OS images and Companion so Pocket Agent / scaffolds
can reuse icons without inventing artwork.

## Icons (`icons/*.svg`)

- Source: [Lucide](https://lucide.dev/) (lucide-icons/lucide)
- License: ISC — https://github.com/lucide-icons/lucide/blob/main/LICENSE
- Names used: app (layout-grid), check, clock, file-code, folder, image, pause,
  play, plus, settings, sparkles, timer, trash, x

## Emoji (`emoji/*.svg`)

- Source: [Twemoji](https://github.com/jdecked/twemoji) (Twitter / community fork)
- License: CC-BY 4.0 — https://creativecommons.org/licenses/by/4.0/
- Codes: 1f44b 👋, 2705 ✅, 1f4a1 💡, 1f680 🚀, 1f4bb 💻, 23f1 ⏱, 1f3a8 🎨

## Usage

On images: `/opt/portable-ai-os/assets/ui-kit/`  
In HTML apps: copy or link relative paths into your project under `/data/projects/`.  
Keep this ATTRIBUTION file (or credit Lucide + Twemoji) when redistributing apps.
